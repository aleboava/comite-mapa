# Pasta privada – nada daqui vai para o GitHub

Esta pasta é ignorada pelo Git (veja `.gitignore`). Ela guarda:

| Caminho | O que é |
|---|---|
| `entrada/` | As exportações do formulário (CSV com nome, e-mail, WhatsApp etc.). Coloque aqui o arquivo do dia. |
| `atribuicoes.csv` | O grupo de cada resposta já processada (`response_id`, `grupo`, `desde`). É a "memória" do sistema: sem ele, ninguém mantém o seu grupo. **Faça backup.** |
| `relatorios/` | Um relatório por execução: pessoas novas por grupo, textos de cidade não reconhecidos e grupos fora da faixa. |

Se precisar mover o projeto para outro computador, copie esta pasta à parte (por um canal seguro), nunca pelo GitHub.
